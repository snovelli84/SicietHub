# Loghi servizio IA aziendale

Stesso stile di SICIET HUB: marchio SICIET sopra, parola sotto con sfumatura blu → verde
(carattere [Russo One](https://fonts.google.com/specimen/Russo+One), licenza OFL).

- `siciet-aria/` – **SICIET ARIA** (scelto): "AR" blu e "IA" verde per evidenziare l'intelligenza artificiale
- `siciet-aria-sfumato/` – SICIET ARIA con sfumatura blu → verde come SICIET HUB
- `siciet-mind/` – alternativa: **SICIET MIND**
- `siciet-ai/` – alternativa: **SICIET AI**

Ogni cartella contiene le stesse misure delle icone del portale (512, 192, 180 Apple, 32 favicon, maskable 512),
pronte per Open WebUI o per aggiungere il servizio in `apps.js` con `icon: "brand/siciet-aria/icon-192.png"`.
